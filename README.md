# Rock-Paper-Scissors Game

A repeatable command-line Rock-Paper-Scissors game. Play as many rounds as you like; the wins, losses, and ties are tracked for the current session and shown after each round and when you quit. The computer chooses each move randomly.

## Run

```powershell
python rock_paper_scissors.py
```

Enter `rock`, `paper`, or `scissors` to play. Enter `q` or `quit` to finish.

## Test

```powershell
python -m unittest -v
```

Requires Python 3.13 and only the standard library.
